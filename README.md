#Verificação de Horas Extras Registradas por Colaborador Semanalmente

O projeto é baseado em um script 100% em Python que realiza o comparativo entre duas tabelas de controle de dados, sendo uma de um chefe/líder de produção
e a outra proveniente do time de RH de uma empresa, na qual o objetivo do programa é comparar as duas tabelas e verificar quais colaboradores realizaram
horas extras naquela semana, facilitando um processo que anteriormente era feito de forma manual.

#Tecnologia

Script em Python, com a junção de algumas outras bibliotecas, como: streamlit (para hospedagem do site), pandas (para comparação e criação da planilha) e io
(gerenciamento do fluxo de memória do computador).
